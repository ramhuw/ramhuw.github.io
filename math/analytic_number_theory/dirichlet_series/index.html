Motivation

Given a positive integer nnn, what is the number of its divisors? This problem appears constantly in coding challenges. Write this number of divisors into a condense form

d(n)≔∑d∣n1,n∈Z+ d(n) \coloneqq \sum_{d \mid n} 1, \quad n \in \mathbb Z_+ d(n):=d∣n∑​1,n∈Z+​

and let us also define this as a function in Julia with Primes.jl and plot the first values with CairoMakie.jl

using Primes
using CairoMakie

function d(n)
    prime_factors = factor(n)
    count = 1
    for (_, e) in prime_factors
        count *= (e + 1)
    end
    count
end

N = 100
ns = 1:N

fig = Figure()
ax = Axis(fig[1, 1],
    xlabel = L"n",
    ylabel = L"d(n)",
    xlabelsize = 20,
    ylabelsize = 20,
    title = "Number of divisors",
    titlesize = 24)

stem!(ax, ns, d.(ns); label=L"$d(n)$")

axislegend(ax;
    position = :lt,
    framevisible = true,
    labelsize = 20)

save(joinpath(@OUTPUT, "divisor_count.svg"), fig)

Seems quite random, however in this article we will discuss the following striking asymptoticity obtained by Dirichlet in 1849

∑n≤xd(n)∼xlog⁡x,x→+∞ \sum_{n \leq x} d(n) \sim x \log x, \quad x \to +\infty n≤x∑​d(n)∼xlogx,x→+∞

as plotted

using CairoMakie

N = 100

function sumd(x)
    sum([d(n) for n in 1:floor(x)])
end

function xlog(x)
    x * log(x)
end

fig = Figure()
ax = Axis(fig[1, 1],
    xlabel = L"x",
    ylabel = L"\sum_{n \leq x} d(n)",
    xlabelsize = 20,
    ylabelsize = 20,
    title = "Asymtote",
    titlesize = 24)

stem!(ax, ns, sumd.(ns); label=L"$\sum_{n \leq x}d(n)$")
lines!(ax, ns, xlog.(ns); color=:red, label=L"$x \log x$")

axislegend(ax;
    position = :lt,
    framevisible = true,
    labelsize = 20,
    rowgap = 4)

save(joinpath(@OUTPUT, "asymtote.svg"), fig)

As shown above, the asymptotic formula is already evident for n≤100n \leq 100n≤100.

The correct way to study ∑n≤xd(n)\sum_{n \leq x}d(n)∑n≤x​d(n) is through its Dirichlet series L(s,d)≔∑n>0d(n)/nsL(s, d) \coloneqq \sum_{n > 0} d(n)/n^sL(s,d):=∑n>0​d(n)/ns. I will present two reasons to introduce Dirichlet series: they capture the algebraic structure behind d(n)d(n)d(n), and their poles and zeros reflects the behavior of ∑n≤xd(n)\sum_{n \leq x} d(n)∑n≤x​d(n) as x→+∞x \to +\inftyx→+∞. This topic will motivate the study of analytic number theory.

Arithmetic Functions and Dirichlet Series

Let us extract the obvious information from the definition d(n)=∑d∣n1d(n) = \sum_{d \mid n} 1d(n)=∑d∣n​1: it is a function defined on Z+\mathbb Z_+Z+​, and the sum is over divisors. This abstracts into the following definition.

Definition. The commutative ring of arithmetic functions is the set of functions

A≔{f:Z+→C} \mathcal A \coloneqq \{f: \mathbb Z_+ \to \mathbb C\} A:={f:Z+​→C}

equipped with pointwise addition and multiplication given by convolution

f∗g(n)≔∑d∣nf(d)g(n/d). f * g(n) \coloneqq \sum_{d \mid n} f(d) g(n/d). f∗g(n):=d∣n∑​f(d)g(n/d).

The function

δ(n)={1,n=1,0,n>1. \delta(n) = \left\{ \begin{array}{ll} 1, & n = 1, \\ 0, & n > 1. \end{array} \right. δ(n)={1,0,​n=1,n>1.​

serves as unity.

For every arithmetic function a(n)a(n)a(n) there is an associated Dirichlet series ∑n>0a(n)/ns\sum_{n > 0}a(n)/n^s∑n>0​a(n)/ns. For now just ignore the convergence issue and consider this as a foraml series. The ring of formall Dirichlet series is nothing but C⟦Z+⟧\mathbb C \llbracket \Z_+ \rrbracketC[[Z+​]], the complete monoid algebra of the multiplicative monoid (Z+,×)(\Z_+, \times)(Z+​,×). Our association defines a ring isomorphism

A≅C⟦Z+⟧,a↦L(s,a)≔∑n>0a(n)ns \mathcal A \cong \mathbb C \llbracket \Z_+ \rrbracket, \quad a \mapsto L(s, a) \coloneqq \sum_{n > 0} \frac{a(n)}{n^s} A≅C[[Z+​]],a↦L(s,a):=n>0∑​nsa(n)​

this would be clear once we notice that for the function

δm(n)=δ(n−m) \delta_m(n) = \delta(n - m) δm​(n)=δ(n−m)

there is

δl∗δm=δlm. \delta_l * \delta_m = \delta_{lm}. δl​∗δm​=δlm​.

Remark. Mapping 1/ps1/p^s1/ps to xpx_pxp​ for each prime ppp gives an isomorphism

C⟦Z+⟧≅C⟦z2,z3,z5,z7,…⟧\mathbb C \llbracket \Z_+ \rrbracket \cong \mathbb C \llbracket z_2, z_3, z_5, z_7, \dots \rrbracketC[[Z+​]]≅C[[z2​,z3​,z5​,z7​,…]]

where the right-hand side is the formal power series ring of independent variables indexed by prime numbers.

Now consider the constant function 1(n)=1\mathbf{1}(n) = 11(n)=1, we immediately check that d=1∗1d = \mathbf{1} * \mathbf{1}d=1∗1, which means L(s,d)=L(s,1)2L(s, d) = L(s, \mathbf{1})^2L(s,d)=L(s,1)2. This L(s,1)L(s, \mathbf{1})L(s,1) is better known as the Riemann ζ\zetaζ function, the central object of analytic number theory. We will study the very basics of ζ(s)\zeta(s)ζ(s), then ζ(s)2\zeta(s)^2ζ(s)2 comes for free. But that will not be helpful unless we understand how L(s,a)L(s, a)L(s,a) can be used to study ∑n≤xa(n)\sum_{n \leq x} a(n)∑n≤x​a(n).

Perron's Formula

If the Dirichlet series L(s,a)=∑n>0a(n)n−sL(s, a) = \sum_{n > 0} a(n)n^{-s}L(s,a)=∑n>0​a(n)n−s converges absolutely at some s∈Cs \in \mathbb Cs∈C, then convergence is guaranteed at every point to the right of sss. If we define

σa≔inf⁡{ℜs∣∑n>0a(n)n−s converges absolutely} \sigma_a \coloneqq \inf \{\Re s \mid \text{$\sum_{n > 0} a(n) n^{-s}$ converges absolutely}\} σa​:=inf{ℜs∣∑n>0​a(n)n−s converges absolutely}

the Dirichlet series will converge as long as ℜs>σa\Re s > \sigma_aℜs>σa​.

Assume ℜs>σa\Re s > \sigma_aℜs>σa​ and apply Abel's summation formula, we have

∑n>0a(n)ns=s∫1+∞A(x)x−s−1dx \sum_{n > 0} \frac{a(n)}{n^s} = s \int_1^{+\infty} A(x) x^{-s - 1} \mathrm d x n>0∑​nsa(n)​=s∫1+∞​A(x)x−s−1dx

where A(x)=∑n≤xa(x)A(x) = \sum_{n \leq x} a(x)A(x)=∑n≤x​a(x). Absolute convergence is necessary since we need to interchange summation and integral.

After a change of variable x=etx = \mathrm e^tx=et, we see that L(s,a)/sL(s, a)/sL(s,a)/s is the Laplace transform of A(et)A(\mathrm e^t)A(et):

L(s,a)s=∫0+∞A(et)e−stdt. \frac{L(s, a)}{s} = \int_0^{+\infty} A(\mathrm e^t) \mathrm e^{-st} \mathrm d t. sL(s,a)​=∫0+∞​A(et)e−stdt.

Apply the inverse Laplace transform and we get

A(x−)+A(x+)2=12πi∫c−i∞c+i∞L(s,a)xssds. \frac{A(x^-) + A(x^+)}{2} = \frac{1}{2\pi \mathrm i}\int_{c - i \infty}^{c + i\infty} L(s, a) \frac{x^s}{s} \mathrm d s. 2A(x−)+A(x+)​=2πi1​∫c−i∞c+i∞​L(s,a)sxs​ds.

where ccc is any real number larger than _sigmaa\_sigma_a_sigmaa​. The left-hand side is often written as ∑n≤x′a(n)\sum'_{n \leq x} a(n)∑n≤x′​a(n), the only difference from the usual ∑\sum∑ is that when xxx is an integer, the last term a(x)a(x)a(x) is replaced by a(x)/2a(x)/2a(x)/2. The above equality is called Perron's formula.

Contour Shifting

The Perron formula is exact, but it gives no information unless we can find the dominant terms. The idea is to shift the integral contour left to get a smaller integral, while the singularities crossed should contribute to the dominant terms.

Take a=1a = \mathbf{1}a=1 for example, in this case A(x)=⌊x⌋∼xA(x) = \lfloor x \rfloor \sim xA(x)=⌊x⌋∼x is obvious, so we expect to obtain the same result from Dirichlet series L(s,1)=ζ(s)L(s, \mathbf{1}) = \zeta(s)L(s,1)=ζ(s). The series

11s+12s+⋯ \frac{1}{1^s} + \frac{1}{2^s} + \cdots 1s1​+2s1​+⋯

converges for ℜs>1\Re s > 1ℜs>1, and has a pole at s=1s = 1s=1. But what is to the left of this pole? The hope is to find a meromorphic function extending ∑n>0n−s\sum_{n > 0}n^{-s}∑n>0​n−s so that we can define ζ(s)\zeta(s)ζ(s) on the points to the left of s=1s = 1s=1. This is called a meromorphic continuation. It turns out that ζ\zetaζ has a meromorphic continuation to the entired complex plane But for our purpose, we just need to extend ζ\zetaζ a little bit left, and the treatment is much easier.

Consider the alternating sum

D(s)=∑n>0(−1)n−1n−s=1−2−s+3−s−4−s+⋯ D(s) = \sum_{n > 0} (-1)^{n-1}n^{-s} = 1 - 2^{-s} + 3^{-s} - 4^{-s} + \cdots D(s)=n>0∑​(−1)n−1n−s=1−2−s+3−s−4−s+⋯

which converges for ℜs>0\Re s > 0ℜs>0 (uniformly in compact subsets). The trick is

ζ(s)−D(s)=2∗(2−s+4−s+6−s+⋯ )=21−sζ(s) \zeta(s) - D(s) = 2 * (2^{-s} + 4^{-s} + 6^{-s} + \cdots) = 2^{1 - s} \zeta(s) ζ(s)−D(s)=2∗(2−s+4−s+6−s+⋯)=21−sζ(s)

and therefore

ζ(s)=D(s)1−21−s \zeta(s) = \frac{D(s)}{1 - 2^{1-s}} ζ(s)=1−21−sD(s)​

for ℜs>0\Re s > 0ℜs>0. The possible poles are from the zeros of 1−21−s1 - 2^{1-s}1−21−s, i.e. s=1+2πilog⁡2m,m∈Zs = 1 + \frac{2 \pi \mathrm i}{\log 2}m, m \in \Zs=1+log22πi​m,m∈Z. Only s=1s = 1s=1 is a pole and to show this we consider another function

D~(s)=1+12s−23s+14s+15s−26s+⋯=(1−31−s)ζ(s) \tilde{D}(s) = 1 + \frac{1}{2^s} - \frac{2}{3^s} + \frac{1}{4^s} + \frac{1}{5^s} - \frac{2}{6^s} + \cdots = (1 - 3^{1-s})\zeta(s) D~(s)=1+2s1​−3s2​+4s1​+5s1​−6s2​+⋯=(1−31−s)ζ(s)

which gives a different expression

ζ(s)=D~(s)1−31−s. \zeta(s) = \frac{\tilde D(s)}{1 - 3^{1-s}}. ζ(s)=1−31−sD~(s)​.

Now the possible poles are of the form s=1+2πilog⁡3m,m∈Zs = 1 + \frac{2\pi \mathrm i}{\log 3}m, m \in \Zs=1+log32πi​m,m∈Z. Now that gcd⁡(2,3)=1\gcd(2, 3) = 1gcd(2,3)=1, the quotient log⁡3log⁡2=log⁡23\frac{\log 3}{\log 2} = \log_2 3log2log3​=log2​3 cannot be a rational number, so s=1s = 1s=1 is the only pole. We may plot the ζ\zetaζ function as follows, the color reflects argument, and brightness reflects absolute value.

using CairoMakie, SpecialFunctions, Colors

# the domain
σs = range(0, 2, length=200)    # real part
ts = range(-1, 1, length=200)  # imaginary part

# evaluate ζ on the grid
Z = [zeta(σ + im*t) for σ in σs, t in ts]

# color each point by hue (arg) and lightness (|ζ|)
function domain_color(z)
    h = (angle(z) / (2π) + 1) % 1        # hue from arg, in [0,1)
    m = abs(z)
    # smoothly map magnitude to lightness: log scale, capped
    l = 0.5 + 0.5 * (2/π) * atan(log(m + 1e-10))
    return HSL(h * 360, 0.85, clamp(l, 0.1, 0.9))
end

img = domain_color.(Z)

fig = Figure(size=(400, 400))
ax = Axis(fig[1, 1],
    xlabel = L"\sigma",
    ylabel = L"t",
    title  = L"\zeta(\sigma + it)",
    aspect = DataAspect()
)

image!(ax, (0, 2), (-1, 1), img; interpolate=false)

save(joinpath(@OUTPUT, "zeta_domain_coloring.png"), fig)
